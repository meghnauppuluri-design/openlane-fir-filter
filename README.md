# openlane-fir-filter

# 15-Tap Transposed FIR Filter: ASIC Implementation & Verification Using OpenLane

> **Process Node:** SkyWater 130nm CMOS (`sky130A`)

## 1. Overview

This repository contains a complete, production-grade implementation of a **15-tap low-pass finite impulse response (FIR) filter**.

- RTL micro-architecture design
- HDL testbench verification 
- Local Icarus Verilog simulation
- GTKWave waveform analysis
- Automated ASIC physical implementation via OpenLane
- Synthesis area/delay trade-off exploration
- Structured debugging and engineering resolution logs

The complete implementation targets the **SkyWater 130nm CMOS (`sky130A`)** process node.

## 7. OpenLane Interactive Flow

After mounting the OpenLane container:

```bash
make mount
```

start the interactive OpenLane shell:

```bash
./flow.tcl -interactive
```

Prepare the FIR design:

```tcl
package require openlane
prep -design fir_new -tag run_01 -overwrite
```

Run synthesis exploration:

```tcl
run_synthesis_exploration
```

Run synthesis:

```tcl
run_synthesis
```

Run floorplanning and power-grid preparation:

```tcl
run_floorplan
run_tap_decap_or
run_power_grid_generation
```

Run placement:

```tcl
run_placement
```

Run Clock Tree Synthesis:

```tcl
run_cts
```

Run routing:

```tcl
run_routing
```

Run physical signoff:

```tcl
run_magic
run_magic_drc
run_lvs
```

## 12. Quick Start

Clone this FIR filter repository:

```bash
git clone <your-repository-url>
cd fir-filter-documentation-sample
```

Run RTL simulation:

```bash
iverilog -o simulation/sim_out.vvp design/src/fir_new.v design/src/tb_fir.v
vvp simulation/sim_out.vvp
```

View the generated waveform:

```bash
gtkwave simulation/fir_sim.vcd
```

For ASIC implementation, clone OpenLane:

```bash
git clone https://github.com/The-OpenROAD-Project/OpenLane.git
cd OpenLane
make mount
```

Then follow:

[**Chapter 5: OpenLane Environment Setup & Interactive ASIC Flow Guide**](docs/05_openlane_interactive_guide.md)

for the complete interactive physical implementation procedure.
